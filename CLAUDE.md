# CLAUDE.md

`BRAIN.md` in this directory is a running scratchpad of ideas and constraints
for `copse` — ideas not yet built, design constraints to respect, open
questions. It is not user-facing documentation; treat it as project memory.

Read it before making non-trivial changes to `copse`, and add to it when a
design decision or idea comes up worth remembering for next time, rather than
letting that context live only in conversation history.
